# Doppledinger

Preservation, research and reconstruction of the **Humdinger computer**.

The Humdinger was demonstrated by Venture Micro at the 1983 West Coast Computer Faire. In September 2026, Aarin (woodson600) shared photographs of a machine he had found at Goodwill, reopening a history previously known to this project mainly through magazine reports.

Nick Taylor began researching the Humdinger in 2020. Aarin's generosity has now made a physical preservation project possible.

**Status, 5 October 2026:** the machine has shipped, with arrival expected on 7 October. Operation, firmware and the board's full configuration remain unverified. The first public account is now available.

The original machine is the **Humdinger**. **Doppledinger** names this project and its possible reconstruction. Recovered material, inferred behaviour and newly created work will be distinguished.

## Project aims

Document the original before intervention; preserve its condition and provenance; trace the circuitry and inventory components; seek original firmware and design records; explore a clearly documented reconstruction. A safe permanent home, potentially a museum, is the long-term aim. No museum arrangement is in place.

## Website and working record

The visitor-facing website lives in `docs/`. Research lives in `research/`; schematics and firmware will be added when they exist. The website can be served directly from this repository's `main` branch and `/docs` directory through GitHub Pages. No dependency installation or build is needed.

The complete private source archive remains outside this repository. Magazine scans are linked rather than bundled. Personal correspondence, shipping details and restricted archives are excluded.
