HUMDINGER — EDITABLE LOGO PACKAGE

BADGE
humdinger-badge.psd: 6000 x 1162 pixels, six separate pixel layers.
humdinger-badge.svg: scalable vector master with named groups.
humdinger-badge.png: full-resolution transparent PNG, 300 ppi metadata.
humdinger-badge-web.png: 1600-pixel-wide web export.

RECTANGULAR BANNER / STICKER
humdinger-rectangle.psd: 6000 x 1219 pixels, five separate pixel layers.
humdinger-rectangle.svg: scalable vector master with named groups.
humdinger-rectangle.png: full-resolution PNG, 300 ppi metadata.
humdinger-rectangle-web.png: 1600-pixel-wide web export.

EDITING
Photoshop layers: Background, Rainbow, Hummingbird, Divider, Lettering;
the badge also has a Border layer. These are independently editable pixel
layers, not live text or Photoshop shape layers. Lettering was traced from
the approved reconstruction, so no font is required. For editing outlines
or resizing without resolution limits, use the SVG masters. All SVG art
is paths and a gradient, with no embedded raster images or external fonts.
Individual SVG and PNG layer sources are included in the layers folder.

WEB
Use the rectangular SVG for resolution-independent display, or the
rectangle-web PNG. Preserve its aspect ratio (approximately 4.92:1).

STICKER PRINTING
The print folder contains a rectangular SVG and 300 ppi PNG set up for
a 6.000 x 1.219 inch finished sticker, with 0.125 inch bleed on every side.
The full bleed artwork measures 6.250 x 1.469 inches. Trim 0.125 inch from
each edge. No crop marks or cutter paths are imposed. Tell the printer
the intended trim size; use their required cutting template if supplied.
This is RGB artwork. Ask the printer to handle conversion to their print
profile and review a color proof. Colors are reconstructed estimates from
the aged original badge. Other sizes can be exported from the SVG master.

VERIFICATION
Both PSDs were reopened and all named layers checked. Reassembling the
saved layers reproduced the stored composite pixel-for-pixel. SVG and
PSD previews were visually inspected. Validation used a PSD reader;
the files were not opened in Adobe Photoshop during this session.

The artwork was rebuilt from the approved digital reconstruction; the
original photographs and earlier PNG remain unchanged.
