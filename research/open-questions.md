# Open questions

These are research tasks, not confirmed diagnoses or instructions to modify the original.

1. Establish firmware location, memory map and socket pinouts through documented continuity work after arrival.
2. Identify sound circuitry and reconcile it with the reported four voices/five octaves.
3. Map physical connectors; compare results with the InfoWorld port list.
4. Identify original hardware designers and BASIC supplier; seek ROM dumps, source, manuals and schematics.
5. Establish whether named customers' orders were delivered, using first-hand evidence or surviving records.
6. Resolve the Quest/Venture connection without treating a name match as proof.
7. Establish provenance before the Goodwill find and whether other machines survive.
8. Assess reference-design similarities only after tracing the actual circuitry.

Convert individual questions to GitHub issues when the project is ready for contributions. Keep settled findings in the documents, with links to the discussion and evidence that established them.
