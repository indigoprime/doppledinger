# Photographs

## Arrival session

Photograph the parcel, unpacking and original condition before intervention. Keep shipping-label images in the private archive. Record loose items, the badge, markings, external views and connector faces. Record both sides of the PCB and chip markings when safely accessible. Photograph before moving wires or removing components; do not power the machine as part of a photographic session.

Preserve untouched originals with a second backup. Assign stable identifiers such as HUM-001, retaining the original filename in the catalogue. Record date, photographer, subject, orientation, any processing and publication permission. Use neutral descriptions instead of unverified component functions.

Public copies should omit private labels and location metadata. Retain enough resolution to read markings and traces. Store annotated or enhanced versions separately from the original and identify the changes. No arrival photographs have been added yet.
